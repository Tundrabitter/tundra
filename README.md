# Tundra

Интерактивное веб-приложение: живая тундра, которая меняется вместе с температурой.

**Демо:** https://tundrabitter.github.io/tundra/

## Что ?!

Тундра реагирует на изменение температуры от −60 °C до +40 °C. Небо, рельеф, растительность, животные и звук. Есть пасхалки, достижения и сценки 
на крайних температурах.

## Стек

- TypeScript
- Vite
- GSAP
- Canvas API
- Web Audio API
- Чистый CSS

## Локальный запуск

npm install
npm run dev

Открывается http://localhost:5173/tundra/

## Сборка

npm run build
npm run preview
